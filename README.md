# 班級經濟

課堂用的班級經濟系統：老師管理計分，學生可以投資、闖關賺取班級幣。純前端靜態網頁，資料由 Google Apps Script 後端存取。

## 頁面

| 檔案 | 說明 | 使用者 |
| --- | --- | --- |
| `index.html` | 入口頁，連到下方三個功能 | 全部 |
| `scoreboard.html` | 班級計分板，管理學生資料與投資設定 | 老師 |
| `invest.html` | 投資市場，K 線、均線、成交量、多標的買賣 | 學生 |
| `game.html` | 闖關挑戰 | 學生 |

## 投資市場

提供乙太幣、黃金、台灣加權指數三個標的，使用真實行情：

- 乙太幣：CoinGecko
- 黃金、台灣加權指數：Yahoo Finance

行情由後端 Apps Script 定期抓取並快取（每 15 分鐘更新一次），買賣結算也在後端完成。

## 使用方式

不需要建置，直接用瀏覽器開啟 `index.html` 即可。也可以用 GitHub Pages 發布成網站。

## 後端

各頁面中的 `SCRIPT_URL` 指向同一個 Google Apps Script 網頁應用程式。後端程式碼不在本儲存庫中。
