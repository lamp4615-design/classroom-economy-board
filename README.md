# 班級經濟

課堂用的班級經濟系統：老師管理計分，學生可以投資、闖關賺取班級幣。純前端靜態網頁，資料由 Google Apps Script 後端存取。

## 頁面

| 檔案 | 說明 | 使用者 |
| --- | --- | --- |
| `index.html` | 入口頁，連到下方三個功能 | 全部 |
| `scoreboard.html` | 班級計分板，管理學生資料與投資設定 | 老師 |
| `invest.html` | 投資市場，K 線、均線、成交量、多標的買賣 | 學生 |
| `game.html` | 闖關挑戰 | 學生 |

## 教師後台（只放本機）

`teacher.html`（教師後台）和 `Code.patched.gs`（後端程式碼）含有學生資料入口與後端細節，已列入 `.gitignore`，**不會推上 GitHub**，只存在老師自己的電腦。這兩個檔案請自行備份（例如複製到雲端硬碟）。

用瀏覽器直接開啟本機的 `teacher.html`，輸入教師密碼即可。資料來自試算表的「歷史紀錄」和「每日快照」，只讀取、不會修改任何資料。

畫面由上到下是：

- **班級概況**：本週有參與的人數、每人平均參與次數、忘物總次數、需要關心的人數、有投資交易的人數。
- **需要關心**：條列學生與具體原因，例如「已連續兩週沒有任何正向參與紀錄」「參與次數比前 3 週明顯減少」「近 7 天忘物 3 次以上」「借款應還不低於現有分數」「月考未達目標」「身價淨值近 7 天下降 10% 以上」。
- **值得肯定**：參與明顯增加、連續 4 週都有參與、樂於幫助同學、投資獲利、月考達標。
- **全班一覽**：每人近 8 週參與的小圖、答題／習作／助人／忘物次數、最近一次參與、淨值變化、投資損益；點欄位標題排序，可切換近 7 天、近 30 天、全部，也能匯出 CSV。
- **個人歷程**（點學生）：自動產生的一段摘要、每週參與長條圖、分數與身價淨值曲線、各項紀錄次數、投資持倉、月考目標狀況，以及老師備註。可以「列印 / 存成 PDF」給親師座談使用。

「正向參與」＝答題、習作、助人、輔導的次數。關心與肯定名單固定用「近 7 天 vs 前 3 週」判斷，不受時間範圍影響。這些提示是幫老師快速找人的線索，**不是對孩子的評價**：沒有紀錄不代表沒有學習，請搭配課堂觀察。試算表紀錄累積不到 14 天時，畫面會提醒趨勢判讀要保守。

老師備註只存在這台電腦的瀏覽器（localStorage），不會上傳；清除瀏覽器資料就會消失，重要內容請另外保存。

首次使用前要設定教師密碼：Apps Script →「專案設定 → 指令碼屬性」→ 新增 `CE_TEACHER_PIN`，值填你要的密碼。後端更新後需重新部署「新版本」。密碼連續輸錯 5 次會鎖定 10 分鐘。

注意事項：
- 密碼只能擋一般人，不是銀行等級的保護。學生姓名與成績屬於敏感資料，建議不要公開這個網頁的網址。
- 試算表的資料最多比實際晚 5 分鐘。
- 學生按「復原」產生的紀錄也會被算進次數，所以次數可能略多於實際。

## 投資市場

提供乙太幣、黃金、台灣加權指數三個標的，使用真實行情：

- 乙太幣：CoinGecko
- 黃金、台灣加權指數：Yahoo Finance

行情由後端 Apps Script 定期抓取並快取（每 15 分鐘更新一次），買賣結算也在後端完成。

## 使用方式

不需要建置，直接用瀏覽器開啟 `index.html` 即可。也可以用 GitHub Pages 發布成網站。

## 後端（Google Apps Script）

各頁面中的 `SCRIPT_URL` 指向同一個 Google Apps Script 網頁應用程式，後端程式碼是本機檔案 `Code.patched.gs`（不在儲存庫中）。資料存在 Google 雲端硬碟的 JSON 檔，並同步一份到 Google 試算表方便老師查看。

### 初次設定或更新後端

1. 開啟 Apps Script 專案，把 `Code.patched.gs` 整份複製，貼進 `程式碼.gs` 覆蓋，按 Ctrl+S。
2. 到「專案設定 → 指令碼屬性」，確認 `CE_API_KEY` 已設定，且和網頁中的 `API_KEY` 完全一致。
3. 在上方函式選單選 **`一鍵設定`**，按「執行」一次。它會一次完成：
   - 每 15 分鐘自動抓真實行情
   - 每 5 分鐘自動把交易同步到試算表
   - 每天凌晨 2 點自動備份並存「每日快照」，每週一凌晨 3 點自動產生週報
   - 立刻抓第一筆行情，並存下今天的快照
4. 「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」→ 部署。

之後如果只是修改程式碼，只要重做第 1 步和第 4 步。`一鍵設定` 重複執行也安全。

### 試算表同步的時間差

學生在投資市場買賣時，系統只更新資料檔，不會當下寫入試算表，所以交易才會快。試算表的「目前總覽」和「歷史紀錄」最多會晚 5 分鐘更新。學生看到的分數和持倉不受影響。

### 老師工具（函式選單中直接執行）

| 函式 | 用途 |
| --- | --- |
| `一鍵設定` | 初次設定，見上方 |
| `手動更新行情` | 立刻抓一次真實行情，不用等 15 分鐘 |
| `diagnoseDataFiles` | 檢查雲端硬碟上有幾份資料檔，有重複時要刪掉多餘的 |
| `rebuildOverview` | 用目前資料重新產生試算表的「目前總覽」 |
| `cleanupSnapshot` | 清掉每日快照的重複列和測試列 |
| `listBackups` / `restoreFromBackup` | 查看每日備份，或還原成某一天的備份 |

### 常見問題

- **函式選單找不到某個函式**：名稱結尾是底線 `_` 的函式不會顯示，這是正常的。要執行的都是上表列出的函式。
- **買賣仍然很慢**：確認已執行過 `一鍵設定`，且部署的是「新版本」。
- **行情顯示「資料較舊」**：執行 `手動更新行情`，並檢查觸發器是否存在（Apps Script 左側時鐘圖示）。
