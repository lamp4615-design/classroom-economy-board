# 計分板與大螢幕模式

[← 回總覽](../README.md)

`scoreboard.html` 是老師管理計分的頁面，也可以切成「大螢幕模式」讓學生在教室大螢幕上自己操作。

## 大螢幕模式（學生端）的限制

- **沒有「輔導」按鈕**：進步分數由學生自己填、沒有驗證，也會和後台的輔導配對重複發分，所以拿掉了。輔導加分只由老師在教師後台的「輔導配對」結算，進步分數由月考紀錄自動計算。計分板（老師端）的學生列也沒有「輔導」按鈕了。
- **螢幕數字鍵盤**：教室大螢幕常沒有實體鍵盤，系統也不一定會自動跳出觸控鍵盤，所以大螢幕模式自己畫了一個數字鍵盤。點到數字欄位（月考目標、月考成績、借入、投資、還款、座號學號等）就會出現；第一次按數字會取代原本的內容（目標預設 80，直接按 9、0 就是 90），小數點只能有一個，最多 8 個字元，按「完成」收起。離開大螢幕模式用的 PIN 欄位也有，實體鍵盤照樣能用。只有大螢幕模式才有，老師端不受影響。請假的「備註」是文字欄位，仍需要系統或實體鍵盤。
- **「月考成績」登記過就不能再送出**：這次月考成績不論是學生自己或老師在後台登記過，按鈕都會變成「已登記」，避免重複加分。老師端的計分板仍可再送一次（視窗會警告）。
